如果到了预计续订日期，ChatGPT Plus 没有继续生效，可以按顺序检查。

登录 ChatGPT，查看：

打开订单详情，确认：

- 订单是否仍在处理中；
- 是否提示重新提交 Session；
- 是否出现“修复订阅”入口；
- 未生效月份是否可以退款；
- 是否需要联系客服处理。

如果已经付款但订阅未生效，不要重复购买。官方退款说明提到，订单仍在处理中、尚未完成履约、订阅未生效，或多月套餐存在未生效月份时，可以联系客服核实是否符合取消或退款条件；已经完成履约且权益生效的订单，因个人原因通常不支持退款。

### 最后再考虑重新购买

只有在客服确认原订单无法继续、未生效部分已经处理，或者账号确实已经恢复 Free 后，才考虑重新下单。

- 原订单截图；
- ChatGPT 订阅状态截图；
- 付款记录；
- 错误提示；
- 客服沟通记录。

这些信息比一句“续费失败了”更容易帮助客服定位问题。
